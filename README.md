# German

Personal learning notes from the **Praelexis German courses**.

Praelexis runs German language classes for its staff. This repository is where
I keep my own notes from those sessions — vocabulary, phrases, grammar points
and pronunciation tips picked up in class and while practising between them.

## Contents

- **[german-notes.md](german-notes.md)** — the consolidated notes:
  - a full pronunciation guide covering every letter, umlaut and letter
    combination, with the nearest English sound
  - greetings and courtesy phrases
  - formal (*Sie*) vs. informal (*du*) address and verb endings
  - introducing yourself, question words, articles and nouns
  - numbers, colours, adjectives and everyday vocabulary

Comparisons to Afrikaans appear throughout, since the shared sounds between
Afrikaans and German are a useful shortcut.

## Notes

These are informal class notes, not a teaching resource — expect gaps and the
occasional half-remembered spelling. Earlier per-session note files were
consolidated into `german-notes.md`; they remain in the git history.
